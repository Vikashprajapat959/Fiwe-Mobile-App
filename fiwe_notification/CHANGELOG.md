## 1.0.0

- Initial release of the in-app notification system for Flutter
- Features:
  - Slide-in animation from top when showing notification
  - Horizontal slide animation for dismissal
  - Auto-dismissal after configurable duration
  - Dismiss to top animation when auto-dismissing
  - Support for icon, title, description, dismiss button, and custom actions
  - Metadata support via Map
  - Overlay-based display system for global accessibility
  - Notification stacking with offset
  - Programmatic dismissal of last notification
- Includes comprehensive unit tests and example implementation
