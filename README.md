# Fiwe – Flutter Mobile Application

A Flutter-based mobile application for the Fiwe platform. This repository is an authorized portfolio snapshot containing project source code and contributions.

## About the Project

Fiwe is built using Flutter and Dart, with Firebase and Huawei Mobile Services (HMS) integrations.

## Tech Stack

- Flutter
- Dart
- Firebase
- Huawei Mobile Services (HMS)
- Android and iOS

## Project Structure

- `lib/` – Main application source code
- `assets/` – Application assets
- `android/` – Android platform files
- `ios/` – iOS platform files
- `fiwe_notification/` – Notification module
- `hms_room_kit/` – HMS room kit

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone this repository.
2. Open the project folder.
3. Run:

   `flutter pub get`

### Firebase Configuration

Firebase configuration files are intentionally excluded from this repository.

Configure your own authorized Firebase project using:

`flutterfire configure`

Add the required local platform configuration files. Do not commit credentials or private configuration.

The application may require additional authorized Firebase, HMS, and backend setup before it can run.
